## Key Capabilities

<CardGrid stagger>
  <Card title="Medical Domain-Aware" icon="information">
    Native support for biomedical imaging standards. Parses DICOM tags, BraTS NIfTI volumes, and SMART metadata directly into semantic attribute trees.
  </Card>
  <Card title="Dynamic Multi-View Engine" icon="laptop">
    Switch working directory projections seamlessly between DICOM hierarchies, BraTS folders, and SMART JSON layouts without duplicating raw data.
  </Card>
  <Card title="Native Large File Storage (LFS)" icon="document">
    Automatic separation of lightweight metadata trees from multi-gigabyte binary assets using high-performance BLAKE3 content-addressed storage.
  </Card>
  <Card title="Zero-Copy Cohort Synthesis" icon="random">
    Synthesize and blend research cohorts across multiple branches and repositories with zero-copy binary linking via `git-med mix`.
  </Card>
</CardGrid>
